## 1. Beeline Business Uzbekistan (РЕКОМЕНДУЕТСЯ)

**Плюсы**:
- Лучшее покрытие UZ-мобильных (сам оператор)
- Безлимитные тарифы внутри Beeline + льготные на другие сети
- Стабильный SIP, низкая задержка (DC в UZ)
- Юридически чисто для B2B в UZ

**Минусы**:
- Требуется юрлицо (ООО/ИП)
- Оформление 5-10 рабочих дней
- Минимальный контракт 6-12 месяцев

**Контакт**: https://beeline.uz/business/ → форма «SIP-транк для колл-центра»
Или напрямую: +998 (78) 140-06-11, corporate@beeline.uz

**Технические детали для конфига**:
- Host: даст менеджер (обычно `sip.beeline.uz` или `voip.beeline.uz`)
- Transport: UDP 5060 (стандарт), TLS доступен по запросу
- Auth: userpass + IP whitelist (обязательно оба)
- Codec: alaw, ulaw, opus

## 2. UzCloud Voice

**Плюсы**:

**Минусы**:

**Контакт**: https://uzcloud.uz → Voice / SIP-транкинг
+998 (71) 200-70-07

## 4. Zadarma (FALLBACK для быстрого старта)

**Плюсы**:
- Онлайн-регистрация за 5 минут
- Не требует юрлица
- Оплата картой, без договора
- Идеально для тестирования концепции

**Минусы**:

- Хуже качество на некоторых UZ-сетях

**Использовать для**: тестирования Фазы 2 на 1-2 неделях,
пока не оформился Beeline. **Не для продакшена!**

**Контакт**: https://zadarma.com — регистрация онлайн, топап карточкой.

**Технические**:
- Host: `sip.zadarma.com`

**Долгосрочно (продакшен на 26+ операторов)**:

процесс занимает 1-2 недели, идёт параллельно с фазой разработки.

**На старте (пилот 3-5 операторов, 1-2 недели)**:

проверяешь всю цепочку CRM → Asterisk → SIP → мобильный клиент → запись.

**Если Beeline требует слишком долгий контракт**:
→ UzCloud как компромисс. Гибче условия, оформление быстрее.

## Чек-лист вопросов менеджеру

При оформлении обязательно уточни:

- [ ] Формат номеров: E.164 (`+998XXXXXXXXX`) или национальный (`8XXX...`) или что-то ещё?
- [ ] Максимум одновременных исходящих каналов?
- [ ] Есть ли CPS (Calls Per Second) лимит? Наши 26 операторов могут дать всплеск 5-10 CPS.
- [ ] Кодеки: поддерживает G.711 (alaw/ulaw)? Opus?
- [ ] Аутентификация: userpass + IP whitelist? IP-only?
- [ ] Возможно ли CallerID подставить наш номер? (обязательно для узнаваемости)
- [ ] Формат ANI/DNIS в SIP-заголовке INVITE (для матчинга в CRM)?
- [ ] Есть ли DID (входящие)? — на Фазу 2 не нужны, но пригодятся в будущем.
- [ ] SLA / уровень поддержки при инцидентах?
- [ ] Возможность DTMF (RFC 2833)? Нужно для IVR в будущем.
- [ ] Fax / T.38 — не нужно, но если продаёт «включённым» — попроси убрать.
