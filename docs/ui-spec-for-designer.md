# naffAI — UI-спецификация для дизайнера

Система учёта продаж и управления операторами колл-центра телефонного магазина.
Документ описывает **только функциональность** — что пользователь видит и делает на каждом экране.
Визуал, палитра, типографика, компоновка — **на усмотрение дизайнера**.

---

## Роли

В системе **две роли**:

- **Менеджер (manager)** — владелец/руководитель. Полный доступ ко всему.
- **Оператор (operator)** — сотрудник колл-центра. Работает со своими лидами и продажами.

Роль определяет: набор пунктов навигации, доступ к экранам, доступные действия на общих экранах.

---

## Общая структура интерфейса

- **Логин** — один экран, вход по логину/паролю. После входа: менеджер → дашборд, оператор → «Мои лиды».
- **Основной layout** — sidebar с навигацией слева + основная рабочая область.
- **Профиль пользователя** — доступен обеим ролям, в правом верхнем углу или как пункт меню.
- **Языки интерфейса** — русский и узбекский (переключается пользователем).
- **Тема** — светлая/тёмная (переключатель в профиле).

9. Зарплата

11. Посещаемость — отчёт
12. Уроки — сегодня
13. Уроки — история
14. Маркетинг
15. Стикеры
16. AI-чат
17. Операторы
18. Пользователи
19. Аудит (журнал изменений)

## 1.1 Дашборд

Стартовый экран менеджера.

**Функции:**
- KPI-карточки: продажи за день / неделю / месяц (кол-во и сумма).
- Кол-во активных операторов сейчас на смене.
- Топ операторов по продажам (за выбранный период).
- Лента последних продаж (реалтайм-обновление).
- Фильтр периода (сегодня / неделя / месяц / кастом).

---

## 1.2 Продажи

### 1.2.1 Список продаж

**Функции:**
- Таблица всех продаж со столбцами: дата, оператор, канал, модель, IMEI, сумма, партнёр, статус (обычная / возврат / подарок).
- Поиск по IMEI, модели, оператору.
- Фильтры: период, оператор, канал, партнёр, статус.
- Постраничная навигация.
- Кнопка «Новая продажа».
- Кнопка «Экспорт в Excel» — скачивает отфильтрованный список.
- Кнопка «Импорт из Excel» — загрузка файла XLSX для массового добавления.
- Клик по строке → карточка продажи.

### 1.2.2 Карточка продажи

**Функции:**
- Все поля продажи в режиме просмотра.
- Кнопки: «Редактировать», «Удалить», «Оформить возврат».
- История изменений записи (кто, когда, что менял).

### 1.2.3 Форма продажи (новая / редактирование)

**Функции:**
- Ввод IMEI — автоматическая проверка на валидность (алгоритм Луна) и подсветка ошибки.
- После валидного IMEI — автозаполнение модели телефона из справочника TAC (первые 8 цифр IMEI).
- Выбор канала продажи.
- Ввод суммы.
- Выбор одного или нескольких операторов, участвовавших в продаже, с указанием % сплита.
- Выбор партнёра (опционально) с указанием % сплита.
- Дата продажи (по умолчанию — сегодня).
- Комментарий.
- Поле «Подарки» — что было подарено при продаже.
- Автоматическое предупреждение о дубле, если такой IMEI уже был продан.
- Кнопки «Сохранить» / «Отмена».

---

## 1.3 Лиды

### 1.3.1 Список лидов

**Функции:**
- Таблица лидов: имя/телефон, источник, назначенный оператор, статус, дата поступления, кол-во звонков.
- Фильтр «Нужна проверка» (в sidebar рядом с пунктом «Лиды» — бейдж с количеством).
- Поиск и фильтры: по источнику, оператору, статусу, дате.
- Мультивыбор строк для массовых операций:
  - Назначить оператора.
  - Переназначить оператора.
  - Снять назначение.
- Кнопка «Конвертировать в продажу» — переход к форме продажи с предзаполненными данными лида.

### 1.3.2 Google-Sheets источники лидов

**Функции:**
- Список подключённых Google-таблиц, из которых импортируются лиды.
- Добавить/редактировать/удалить источник (URL таблицы, лист, маппинг колонок).
- Кнопка «Синхронизировать сейчас».
- Статус последней синхронизации.

---

## 1.4 Звонки

**Функции:**
- Журнал звонков операторов (кто звонил, кому, когда, длительность, результат).
- Фильтр по оператору, лиду, дате.
- Heatmap колбэков (тепловая карта по дням/часам).

---

## 1.5 Аналитика

**Функции:**
- Leaderboard операторов (сортировка по продажам, сумме, конверсии).
- Разрезы: по каналам продаж, по моделям телефонов.
- Временные ряды (график продаж во времени).
- Воронки операторов (лиды → звонки → продажи).
- Тепловая карта колбэков.
- Распределение лидов по операторам.
- Выбор периода и фильтры.
- Экспорт отчёта в Excel.

---

## 1.6 Табло (leaderboard fullscreen)

**Функции:**
- Полноэкранный режим для отображения на большом мониторе в офисе.
- Топ операторов по продажам за день / месяц.
- Крупные цифры, авто-обновление каждые 30 секунд.
- Без sidebar и лишних элементов — максимально «на весь экран».

---

## 1.7 Каталог

**Функции:**
- **Модели телефонов** — CRUD (название, бренд, категория).
- **Партнёры** — CRUD (название, % сплита по умолчанию).
- **Каналы продаж** — CRUD (например, «магазин», «онлайн», «партнёр X»).
- **TAC-коды** — справочник соответствия «первые 8 цифр IMEI → модель телефона», CRUD.

---

## 1.8 Зарплата

**Функции:**
- Список правил начисления зарплаты (порог продаж → % / фикс).
- CRUD правил.
- Расчёт зарплаты по месяцу и оператору:
  - Кол-во продаж, сумма, начисление, бонусы, штрафы, итог.
- Кнопка «Экспорт в Excel» (сводный отчёт).
- Выбор месяца.

---

## 1.9 Посещаемость

### 1.9.1 Сегодня

**Функции:**
- Реалтайм-список: кто на смене прямо сейчас, кто опоздал, кто не пришёл.
- Ручной check-in / check-out за оператора (менеджер может отметить вручную).
- Список последних отметок (кто когда пришёл/ушёл).

### 1.9.2 Отчёт

**Функции:**
- Сводная таблица посещаемости по операторам за период.
- Столбцы: явки, опоздания, ранние уходы, отработано часов.
- Экспорт в Excel.
- Настройка правил расписания (график смен, допустимое опоздание) — CRUD.

---

## 1.10 Уроки (обучение операторов)

### 1.10.1 Сегодня

**Функции:**
- Просмотр AI-сгенерированного разбора вчерашнего рабочего дня для каждого оператора.
- Список уроков за день.
- Кнопка «Сгенерировать разбор для оператора».

### 1.10.2 История

**Функции:**
- Архив всех уроков с фильтром по оператору и дате.
- Клик по уроку → полный текст разбора.

---

## 1.11 Маркетинг

**Функции:**
- AI-инсайты: система анализирует данные и предлагает идеи (какие каналы работают лучше, какие модели растут и т.д.).
- Кнопка «Сгенерировать новый инсайт».
- Список ранее сгенерированных инсайтов.

---

## 1.12 Стикеры

**Функции:**
- Каталог стикеров/значков, которые менеджер может выдавать операторам за достижения.
- Назначение стикера конкретному оператору (появляется в его профиле).
- CRUD стикеров (название, изображение, описание).

---

## 1.13 AI-чат

**Функции:**
- Чат-ассистент менеджера (доступен только менеджеру).
- Помогает искать данные, отвечать на вопросы про продажи / операторов / KPI.
- История диалогов.
- Ввод сообщения → ответ AI + возможные действия (например, «показать продажи за неделю»).

---

## 1.14 Операторы

### 1.14.1 Список операторов

**Функции:**
- Таблица операторов: имя, телефон, статус (активен / уволен), продажи за месяц, стикер.
- Поиск по имени.
- Клик по строке → карточка оператора.
- Кнопка «Добавить оператора».
- Кнопки быстрых действий на строке (для менеджера): назначить план, назначить стикер, удалить.

### 1.14.2 Карточка оператора

**Функции:**
- Профиль: имя, телефон, дата найма, роль, стикер.
- Статистика: продажи, суммы, конверсия, посещаемость за период.
- Список последних продаж и лидов.
- Диалоги оператора в Telegram (если подключён личный TG-аккаунт).
- Мастер подключения Telegram-аккаунта (TgConnectWizard) — пошаговая привязка.
- Кнопки: редактировать, сбросить пароль, отключить.

---

## 1.15 Пользователи

**Функции:**
- Список всех учётных записей в системе.
- CRUD пользователей: имя, логин, пароль, роль (**только менеджер или оператор**).
- Сброс пароля.
- Активация / деактивация.

---

## 1.16 Аудит

**Функции:**
- Журнал всех изменений в системе: кто, когда, что изменил (какая сущность, старое значение → новое).
- Фильтры: по пользователю, дате, типу сущности (продажа / лид / оператор и т.д.).
- Поиск.
- Только просмотр — редактирование запрещено.

# ЧАСТЬ 2. ОПЕРАТОР

## Навигация оператора

Пункты в sidebar:

1. Мои лиды
2. Уроки — сегодня (с красной точкой при новом уроке)
3. Уроки — история
4. Профиль

Отдельный публичный экран (без входа в систему): **QR-check-in** (`/scan`) — доступен по прямой ссылке или QR-коду на входе в офис.

---

## 2.1 Мои лиды (главный экран оператора)

**Функции:**
- Три вкладки: **Активные** / **Отложенные** / **Все**.
- Список назначенных оператору лидов: имя, телефон, статус, время следующего колбэка, кол-во звонков.

**Быстрые действия на каждом лиде:**
- **«+7 назв»** — быстрое переименование лида (шаблон для нового имени).
- **«Позвонил»** — отметить звонок.
- **Переход в Telegram** — открыть чат с клиентом в Telegram.
- **Callback** — запланировать перезвон, отложить (snooze), отметить сделанным (done).

**Дополнительно:**
- **Модалка-напоминание** (watcher): срабатывает автоматически, когда наступает время запланированного колбэка. Со звуком. Кнопки: «Позвонить сейчас» / «+15 минут».
- **Блокирующий баннер** сверху экрана, если есть просроченные колбэки — оператор не может продолжать работу, пока не разберёт.

---

## 2.2 Уроки

### 2.2.1 Сегодня

**Функции:**
- Свой AI-сгенерированный разбор вчерашнего дня.
- В навигации горит **красная точка**, если урок ещё не открыт.
- Полный текст, рекомендации.

### 2.2.2 История

**Функции:**
- Свои уроки за прошлые дни.
- Фильтр по дате.

---

## 2.3 Профиль

**Функции:**
- Имя, роль, стикер.
- Сброс своего пароля.
- Мастер подключения личного Telegram-аккаунта (TgConnectWizard) — чтобы оператор мог вести переписку с клиентами прямо через систему.
- Утреннее приветствие (morning greeting) — попап при первом входе за день.
- Переключатель языка (RU / UZ).
- Переключатель темы.

---

## 2.4 QR-check-in (публичный экран `/scan`)

**Функции:**
- Экран открывается по QR-коду на входе в офис.
- Оператор сканирует QR → попадает на экран → отмечает свой приход/уход.
- Не требует входа в систему (публичный).
- Отображает: имя оператора, время отметки, подтверждение.

# ЧАСТЬ 3. TELEGRAM-БОТ (для операторов)

Оператор может работать не только через веб, но и через Telegram-бота.

## Команды и функции бота

**Начало работы:**
- `/start` — приветствие и главное меню.
- `/link_operator` — привязать свой Telegram к учётке оператора по номеру телефона.
- `/language` — переключить язык бота (RU / UZ).

**Продажи:**
- `/new` — оформить новую продажу через пошаговый диалог:
  1. Модель телефона.
  2. IMEI (с проверкой на валидность и автозаполнением модели).
  3. Сумма.
  4. Операторы + сплит (%).
  5. Партнёр (опционально) + сплит.
  6. Дата.
  7. Комментарий.
  8. Подтверждение → создание продажи.

**Отчёты и подписки:**
- `/report` — быстрый отчёт по своим продажам.
- `/subscribe` — подписаться на уведомления (о новых лидах, KPI и т.д.).
- `/unsubscribe` — отписаться.

**Посещаемость:**
- `/checkin` — отметить приход на смену.
- `/checkout` — отметить уход.
- `/status` — текущий статус (на смене / нет).

**Callback-кнопки под сообщениями:**
- «Дело сделано» (cb-done).
- «Отложить» (cb-snooze).
- Подтверждение автоматического checkout.
- «Продолжить работать» (когда система предлагает завершить смену).

# ЧАСТЬ 4. ОБЩИЕ ЭЛЕМЕНТЫ (для обеих ролей)

## Логин
- Логин + пароль.
- Кнопка «Забыл пароль» — сброс.
- Переключатель языка (RU / UZ) на экране входа.

## Утреннее приветствие
- Всплывает у оператора при первом входе за день. Мотивационное сообщение, цитата, план на день.

## Уведомления
- Тост-нотификации о событиях (новая продажа сохранена, лид назначен, колбэк наступил и т.д.).
- Звуковые уведомления для callback-модалки.

## Ошибки и валидация
- Единый стиль отображения ошибок форм (валидация IMEI, обязательные поля).
- Единый стиль пустых состояний (empty state) — например, «У вас пока нет лидов».

# Приоритеты для дизайнера

Ключевые экраны, которые дизайнер должен проработать в первую очередь:

**Оператор (то, что он видит каждый день, целый день):**
1. **«Мои лиды»** — главный рабочий инструмент, максимум внимания к юзабилити (быстрые действия, watcher-модалка, баннер просрочек).
2. **QR-check-in** — быстрый, крупный, для мобильного экрана.
3. **Профиль + мастер подключения Telegram**.

**Менеджер (то, что смотрит каждый день):**
1. **Дашборд** — KPI сразу видны.
2. **Табло (leaderboard)** — красиво на большом экране в офисе.
3. **Список лидов** + массовые действия.
4. **Форма продажи** — сложная, много полей, критично не запутать оператора.
5. **Аналитика** — читаемые графики.

**Второстепенные:**
- Каталог, пользователи, аудит — служебные экраны, минимум декора.
- Уроки, маркетинг, AI-чат — тексто-центричные экраны.
